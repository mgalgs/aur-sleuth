This behavior is dangerous because it introduces a remote, unauthenticated dependency at build time: an attacker who compromises the SourceForge RSS feed or performs a MITM attack could redirect the download to a malicious binary. Furthermore, this dynamic resolution bypasses AUR's normal review process, as the actual binaries come from an external, mutable source not visible in the PKGBUILD itself. Prebuilt kernel packages are already high-risk; combining them with dynamically resolved, remotely fetched sources significantly increases supply-chain risk.
