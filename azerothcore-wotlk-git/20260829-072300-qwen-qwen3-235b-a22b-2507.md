Combined with the use of `sudo ln -s` and `sudo cp` to write files into system directories (`/usr/share/azerothcore`, `/etc/azerothcore`) from arbitrary user-controlled locations (`/usr/src/acore-modules`), this creates a privilege escalation vector.
