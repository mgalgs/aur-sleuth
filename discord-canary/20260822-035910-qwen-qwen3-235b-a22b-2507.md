## discord-canary

Status: UNSAFE

Summary: Downloads and executes unverified remote code

Details:

The script downloads and executes code from a remote server (`https://updates.discord.com/`) without verification, using a bootstrap mechanism that locates and runs an `updater_bootstrap` binary from untrusted paths (`/usr/share`, `/opt`, or the script's own directory). This pattern allows an attacker who compromises the update server or injects a malicious binary in those locations to execute arbitrary code with the user's privileges.

The most critical issue is that the script delegates control to an external binary (`updater_bootstrap`) which is not verified for authenticity or integrity. If an attacker places a malicious binary at `/usr/share/$BOOTSTRAP_SUFFIX` or `/opt/$BOOTSTRAP_SUFFIX`, it will be executed with no checks. This creates a privilege escalation and persistence vector, especially since these directories may be writable by root or other system users. The use of `exec` after the bootstrap also means the malicious code runs in place of the original script, evading simple process monitoring.

Additionally, the script creates user-writable directories under `$XDG_CONFIG_HOME` and executes binaries from there, which could be exploited if the update mechanism is hijacked. While Discord Canary is a legitimate application, this implementation lacks any signature checking or hash verification for downloaded components, enabling supply-chain attacks.
