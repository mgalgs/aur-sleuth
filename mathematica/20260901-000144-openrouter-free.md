```bash
if [[ ${SKIP_DYNAMIC_SIGNATURE:-${PRINTSRCINFO}} != 1 ]]; then
  _dynamic_signature=$(
    set -o pipefail
    curl -fsSL https://www.wolfram.com/download-center/ \
      | grep -oP "\bhref=\"${_source_url/./\.}\?[^\"]+\K&amp;signature=[a-zA-Z0-9]+(?=\"|&)" \
```

During `makepkg --printsrcinfo`, `PRINTSRCINFO=1` is set, so the condition evaluates to false and the curl does NOT run. This is documented standard practice for the Mathematica package, which requires a dynamic signature parameter for downloads. No data is exfiltrated, no downloaded code is executed, and the destination is the package's own vendor. The rest of the top-level code consists of standard variable assignments and an `IFS` read for version parsing. `prepare()`, `build()`, and `package()` are not executed under `--nobuild --noprepare`.
