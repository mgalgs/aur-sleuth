These capabilities allow loading eBPF programs and accessing performance monitoring subsystems, which can be abused for privilege escalation or stealthy kernel-level attacks. Such privileges are excessive for a typical network monitoring tool and are not justified by the package name or common functionality.

The use of `setcap` in a post-install script without verifying the integrity or ownership of the target binary increases the risk of exploitation during package installation or upgrade.
