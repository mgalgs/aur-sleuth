- This introduces a supply-chain risk: if the `gcloud` binary were compromised or altered upstream, it could execute arbitrary behavior during this step.

While the rest of the PKGBUILD follows standard practices (checksums on sources, proper file extraction, no suspicious external downloads), this use of `gcloud` to self-install components at build time deviates from safe, reproducible packaging norms. It effectively allows unreviewed, potentially executable code to be pulled in during build, bypassing AUR’s source verification model.

This pattern is not typical for AUR packages and constitutes a dangerous anti-pattern, especially given the lack of transparency and control over what is installed.
