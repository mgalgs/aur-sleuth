The combination of `LD_LIBRARY_PATH` manipulation and `--no-sandbox` is particularly concerning because it weakens two layers of defense: library integrity and process isolation. Although the script itself does not directly download or execute external code, it creates conditions where such attacks become feasible if the installation directory is tampered with.
