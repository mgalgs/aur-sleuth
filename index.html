How to read this page

These audits look for one thing: code injected into the AUR packaging of a package — in the PKGBUILD, an .install hook, or a patch. They do not rate the application itself.

  • Clean — nothing found, or a flag a judge overturned.
  • No verdict — no model reached an answer either way. Missing information, not a suspicion.
  • Worth a closer look — something flagged it and nothing has settled it. Usually a false positive about behaviour the application is supposed to have; not a claim that it is malicious.
  • Confirmed malicious — two independent audits said unsafe and a judge agreed.

Open a package to see every report, the files each one flagged, and the lines it quoted.
