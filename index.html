These audits look for one thing: code injected into the AUR packaging of a package — in the PKGBUILD, an .install hook, or a patch. “No verdict” means no model reached an answer either way — missing information, not a suspicion. “Worth a closer look” means something did flag the package and nothing has settled it since; that is usually a false positive about behaviour the application is supposed to have, and it is not a claim that the package is malicious. Only “confirmed” means the audits and the judge agreed, and a verdict a judge overturned is struck through rather than left standing.
