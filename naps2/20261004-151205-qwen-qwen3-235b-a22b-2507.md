Pulling arbitrary binaries from the host system during packaging creates a supply-chain risk, as it allows unknown code to be silently included in the final package. Even if intended as a "dirty fix", this undermines trust in the package integrity.

The use of a glob pattern (`**/10.*/`) further suggests automation over control, increasing the risk of including an unintended or malicious version of the library. Combined with the lack of any validation, this constitutes a clear supply-chain vulnerability.
