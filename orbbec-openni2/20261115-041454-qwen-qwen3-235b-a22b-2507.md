The change from `0666` (world-readable/writable) to `0660` (owner/group readable/writable) combined with `uaccess` ensures that only the active user session can access the device, reducing the attack surface compared to globally accessible devices. This is consistent with upstream Linux security practices and does not introduce any malicious behavior, backdoors, or supply-chain risks.
