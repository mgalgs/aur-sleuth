<details>
This is a straightforward launcher/wrapper shell script for the `mcpp-bin` AUR package. Its purpose is clearly documented in the comments: the `mcpp` binary resolves its `MCPP_HOME` via `/proc/self/exe` (real path), so installing it as a plain symlink in `/usr/bin` would cause it to attempt writing its registry sandbox and caches into the root-owned `/opt/mcpp` tree. The wrapper solves this by setting two environment variables (`MCPP_HOME` and `MCPP_VENDORED_XLINGS`) to appropriate per-user and read-only locations before `exec`ing the actual binary.

The script uses standard, transparent shell idioms: `set -eu` for safety, `${VAR:-default}` parameter expansion to honor any user-exported values while providing sensible defaults, and `exec` to replace the shell with the binary while passing all arguments through (`"$@"`). There is no obfuscation, no `eval`, no `base64`, no network calls, no downloads, no file exfiltration, and no writes outside the expected `$HOME/.mcpp` user directory. The destination binary lives at the package's own declared install path (`/opt/mcpp/bin/mcpp`). This is entirely consistent with normal AUR packaging practices for `-bin` packages.
</details>
