However, combining automatic installation (`-s` pulls dependencies, `-i` installs) with unverified upstream changes and silent execution in CI environments increases the attack surface significantly. The most dangerous line is `makepkg -si`, which performs installation as root if the user has sudo rights, without any interactive confirmation or security checks.
