For example, a prompt like "What's in !{rm -rf ~}?" would execute the destructive command silently before sending the transformed text to the agent. The lack of input validation, combined with the use of `bash -c` on untrusted input, constitutes a critical command injection vulnerability.

This behavior fundamentally elevates user input to executable code without sandboxing, confirmation, or access control, making it trivial to exploit for data exfiltration, system modification, or remote code execution if the agent runs in a privileged context.
