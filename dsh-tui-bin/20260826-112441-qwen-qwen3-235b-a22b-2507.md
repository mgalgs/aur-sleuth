<details>
The `dsh-tui-bin.install` script contains a `sync_profile` function that, during package installation or upgrade, executes code as a regular user without their consent. It identifies a user with UID between 1000 and 65534, then uses `runuser` to run the command `/usr/bin/dsh plugin --profile dsh-tui add "@deepseek-harness-tui/dsh-tui@$ver"` under that user's context.

This behavior is dangerous because it automatically runs a command that modifies user-specific application state (a plugin profile) without explicit user interaction or approval. The use of `yes | timeout 300 runuser -u ...` suggests it may be feeding input or bypassing prompts, increasing risk. While the command appears related to the application, silently executing user-level commands during package management violates the principle of least surprise and could be abused to exfiltrate data or escalate privileges if the `dsh` binary is compromised.

This constitutes a supply-chain risk: the AUR package is performing unauthorized user-level actions outside the scope of standard package installation.
</details>
