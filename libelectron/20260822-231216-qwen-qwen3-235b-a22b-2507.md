The script `twitch-videoad.js` is a browser extension or userscript designed to block ads on Twitch by intercepting and modifying video stream requests. While ad-blocking itself is not inherently malicious, this script exhibits several dangerous behaviors that go beyond typical content filtering.

Although the script appears to use these tokens only to request alternative ad-free streams from Twitch's own infrastructure (e.g., via `usher.ttvnw.net` and `gql.twitch.tv`), it collects and reuses authentication material in unauthorized ways. Furthermore, the use of `XMLHttpRequest` to synchronously fetch and parse internal worker scripts, combined with dynamic code generation and `eval`, increases the attack surface and obfuscates intent.

These behaviors — particularly the interception and reuse of authentication headers and device identifiers — represent a clear deviation from benign ad-blocking and demonstrate the potential for abuse of user credentials, making this script unsafe.
