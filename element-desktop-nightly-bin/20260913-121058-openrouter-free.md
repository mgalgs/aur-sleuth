<decision>UNSAFE</decision>
<details>
The file `element-desktop-nightly.sh` is a launcher script that uses `LD_PRELOAD=/usr/lib/libsqlcipher.so` before executing the main binary. This forces the `libsqlcipher.so` shared library to be loaded into the process memory space of the Element Desktop nightly application before it starts. This is a known supply-chain attack technique: a preloaded library can intercept and override standard library functions (e.g., `open`, `read`, `write`, network calls) to exfiltrate data, read credentials, or establish covert connections. The `-bin` package variant means the main binary is downloaded rather than built from source, making it impossible to audit. There is no legitimate reason why a messaging desktop application would need to globally preload a SQLCipher database encryption library via `LD_PRELOAD`.
</details>
