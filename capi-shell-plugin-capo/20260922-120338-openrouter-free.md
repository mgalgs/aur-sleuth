This script contains a command injection vulnerability via the `$tool` variable. The value of `$tool` comes from either the `API_ENDPOINT_PROXY_TOOL` environment variable or the output of `capi_shell_plugin_config`, both of which are user-controlled. It is then interpolated directly into a command name without sanitization:


If `$tool` contains shell metacharacters (e.g., `foo; rm -rf / #`), this becomes arbitrary command execution. Additionally, the script sources all `.sh` files from `providers/` and `tools/` subdirectories without integrity verification, meaning any file placed in those directories would be executed with the privileges of the shell.
